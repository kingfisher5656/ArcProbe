The public level and difficulty-alias index is the selected metadata snapshot
already distributed in ArcPotApk, derived from its supplied game7.0.255 catalogue.
It contains no player data or artwork. Song identities, catalogue, artwork and
associated marks belong to lowiro and their respective credited artists/licensors.

The exact arithmetic is ported from ArcPotApk Rating.java, inspected 2026-10-07.
It remains an inherited saved-score estimate pending comparison with current
official website results. Neither dated metadata nor this rule version is claimed
to be current. No private dump or artwork is bundled.

Consultant title aliases: factual song titles, chart difficulties and song identifiers extracted from the public game song catalog previously available in the local ArcPotApk reference project. Titles/identifiers only; no images, audio, credentials or user scores. Snapshot contains 553 songs; unmatched/newer songs require current catalog metadata.

Explicit consultant workbook aliases distinguish Genesis (Arcaea / CHUNITHM) and Quon (Lanota / WACCA); localized plain-title aliases cover Anokumene, Alice a la mode, neo kosmo and II. These are exact mappings verified against the catalog, not fuzzy title matches. Unavailable or unknown charts remain skipped.
